# LightJPEG 1.1.1

[言語一覧](../../README.md) · [最新版をダウンロード](https://github.com/Uncas-X/LightJPEG/releases/latest)

LightJPEG は MozJPEG 4.1.5 を内蔵した、macOS ネイティブのオフライン画像圧縮アプリです。画像をアップロードする必要はありません。ファイル名は `LightJPEG.app` で、実行時に追加の依存ソフトウェアは不要です。macOS 13 以降に対応し、Universal バイナリに Intel と Apple Silicon の両アーキテクチャを含みます。Intel Mac の macOS 15.7.9 で実機検証済みです。arm64 はクロスコンパイルのみ完了しており、実機では未検証です。配布版は ad hoc 署名で、Apple の公証は受けていません。

画面と説明文書は 16 言語に対応します：简体中文、English、繁體中文、日本語、한국어、Français、Deutsch、Español、Italiano、Português (Brasil)、Русский、العربية、हिन्दी、Türkçe、Nederlands、Polski。画面の言語は初期状態でシステム設定に従い、手動で選んだ言語も記憶します。アラビア語は右から左のレイアウトになります。

## 使い方

1. 「画像を追加」をクリックするか、画像やフォルダをドロップします。JPEG、PNG、HEIC/HEIF、TIFF、WebP、BMP を読み込み、JPEG として保存します。
2. 画質、サイズ、色の設定を選びます。既定の画質は 75 で、元のサイズを維持します。長辺の上限を指定して縮小できますが、拡大はしません。4:4:4 は文字や色の境界に適していますが、ファイルが大きくなる場合があります。JPEG は非可逆圧縮です。75 はエンコーダの品質値であり、画質を 75% 残す意味でも、一定の圧縮率を保証する値でもありません。
3. 「EXIF 情報を保持」は既定でオフです。有効にすると GPS 位置情報も保持します。GPS 専用のスイッチはありません。「すべて圧縮」をクリックし、保存先フォルダを選んで「圧縮して保存」をクリックすると、各画像が完成した時点で自動保存されます。フォルダ選択をキャンセルした場合は、以前の結果が残ります。

保存名には元の名前に `_compressed` を付け、重複時には一意の番号を追加します。元の画像や既存ファイルは上書きしません。圧縮の停止、一覧の消去、アプリの終了後も、保存済みの画像は残ります。プレビューの見出しには書き出しボタンを表示しませんが、メニューや画像の右クリックメニューから別名保存できます。圧縮に成功して自動保存だけが失敗した結果も、ここから保存し直せます。容量と節約量は、選択中の画像だけの値です。

## 比較表示と画像の扱い

「全体を表示」では画像全体をウインドウに収めます。「1:1 ピクセル」ではフル解像度を読み込み、出力画像の 1 ピクセルを画面の物理 1 ピクセルに対応させます。Retina の倍率も正しく扱います。スクロールや画像のドラッグで移動し、仕切り線をドラッグして比較できます。縮小して出力した場合、元の画像を出力サイズに合わせ、同じ範囲を比較します。

透明部分は白で塗りつぶし、色を sRGB に変換して ICC プロファイルを埋め込み、画像の向きを正規化します。EXIF 保持を有効にすると、標準の Exif、ExifAux、TIFF、GPS フィールドを保持し、向きと寸法を補正します。メタデータの書き込みで再度の非可逆圧縮は行いません。MakerNote、XMP/IPTC、古いサムネイル、アニメーション、Live Photo の付随コンテンツ、HDR 補助データは保持しません。複数ページ・複数フレームのファイルは、最初のフレームのみ処理します。

1 バッチは最大 1,000 枚、入力画像は最大 100 MP（1 億画素）、出力画像の各辺は最大 65,500 ピクセルです。結果が元のファイルより大きくなる場合は、画質を下げてみてください。

| ショートカット | 操作 |
| --- | --- |
| `⌘O` | 画像を追加 |
| `⌘Return` | すべて圧縮（保存先を選択） |
| `Esc` | 実行中の圧縮をキャンセル |
| `⌘S` | 選択した結果を別名保存 |
| `⌘⇧R` | 保存先フォルダを開く |
| `⌘Q` | 終了 |

## ビルドと検証

Xcode とそのコマンドラインツールを用意し、リポジトリのルートで実行します。

```sh
bash build.sh
```

`build/LightJPEG.app` が生成されます。内蔵エンコーダの再ビルドには CMake も必要です。

```sh
bash build-engine.sh
```

エンコーダは MozJPEG `v4.1.5` に固定しています。`vendor/mozjpeg-v4.1.5.tar.gz` を同梱しているため、必要なビルドツールがあればオフラインで再ビルドできます。アーカイブの SHA-256 は次のとおりです。

```text
9fcbb7171f6ac383f5b391175d6fb3acde5e64c4c4727274eade84ed0998fcc1
```

全テストの実行には、ログイン済みの macOS デスクトップセッションが必要です。画面のない環境ではネイティブ操作テストを省略できます。既存の HEIC ファイルを使う場合は `LIGHTJPEG_HEIC_FIXTURE` にパスを指定します。

```sh
bash test.sh
LIGHTJPEG_SKIP_UI_TESTS=1 bash test.sh
LIGHTJPEG_HEIC_FIXTURE=/path/to/sample.heic bash test.sh
```

検証対象は、画像の 8 種類の向き、縮小、4 形式のメタデータ保持と二重の非可逆圧縮がないこと、安全な別名保存、自動保存、キャンセル、保存失敗からの復旧です。ローカライズは 16 × 94 個の文言キーと 33 個の言語・地域ケースを検証します。ピクセル比較には 40 個のネイティブ操作アサーションがあり、中国語・ドイツ語・アラビア語の画面と、2 枚の画像がある一覧での選択画像ごとの容量表示も確認しています。
