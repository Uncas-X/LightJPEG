# LightJPEG 1.1.1

LightJPEG — нативное приложение для сжатия изображений на macOS 13 и новее. Обработка полностью локальная: фотографии не загружаются на сервер, нет онлайн-API, рекламы и телеметрии. В приложении уже есть MozJPEG; для запуска не нужны Homebrew, Node.js или Python. Универсальная сборка содержит программы для Intel и Apple Silicon.

## Начало работы

1. Откройте `LightJPEG.app`. При желании перенесите его в папку «Программы».
2. Добавьте изображения или перетащите файлы и папки в окно. Поддерживаются JPEG, PNG, HEIC/HEIF, TIFF, WebP и BMP; папки просматриваются рекурсивно, повторные пути исключаются.
3. Выберите качество: по умолчанию 75. Можно ограничить длинную сторону или сохранить исходные размеры. Маленькие изображения не увеличиваются. Режим 4:4:4 лучше сохраняет цветные края, например текст; стандартный 4:2:0 обычно даёт меньший файл.
4. При необходимости включите сохранение EXIF. Этот единственный переключатель также сохраняет GPS; по умолчанию он выключен.
5. Нажмите «Сжать всё», выберите папку назначения и подтвердите выбор кнопкой «Сжать и сохранить». Результаты сохраняются автоматически, по одному, сразу после обработки.
6. Выберите изображение в списке для сравнения. Кнопка открытия папки результатов показывает сохранённые файлы.

JPEG использует сжатие с потерями. Значение 75 — параметр кодировщика, а не «75% качества» или обещание уменьшить файл на 75%. Маленький или уже оптимизированный файл может стать больше; приложение показывает это, а не подменяет результат исходником.

## Сохранение и отмена

Результат всегда имеет формат JPEG. К имени добавляется `_compressed`, а при совпадении имени — номер. Исходники и существующие файлы не перезаписываются. При повторном сжатии создаются новые файлы.

Отмена выбора папки не запускает обработку и не удаляет предыдущие результаты. Уже сохранённые изображения остаются на диске после отмены задания, очистки списка и выхода из приложения. Копирование текущего результата на медленный диск может завершиться до остановки очереди.

Если сжатие удалось, но сохранить файл не получилось, результат остаётся доступен в текущем сеансе. Выберите его и сохраните копию через меню «Файл», контекстное меню списка или `⌘S`, указав другую папку. В версии 1.1.1 отдельная кнопка экспорта из панели предпросмотра убрана: для обычной работы достаточно автоматического сохранения. Невосстановленные временные результаты могут быть удалены при очистке списка, повторном сжатии или выходе.

## Сравнение и статистика

Размер исходника, размер результата, процент и число сэкономленных байтов под предпросмотром относятся к **выбранному изображению**, а не ко всей очереди. До обработки вместо результата отображается `—`. Сообщение о завершении отдельно сообщает количество файлов в партии.

- **«Изображение целиком» (Fit):** показывает изображение целиком.
- **1:1:** использует полное разрешение; один пиксель результата соответствует одному физическому пикселю дисплея, в том числе Retina. Прокручивайте колесом или трекпадом либо перетаскивайте область изображения для перемещения. Перетаскивание разделителя меняет границу сравнения.

Если размер уменьшен, масштаб 1:1 рассчитывается по результату, а исходник отображается в той же области для сравнения. До сжатия режим 1:1 показывает исходник.

## EXIF, цвет и ограничения

Ориентация исправляется по EXIF, включая отражения. Прозрачность заменяется белым фоном, цвета переводятся в sRGB с внедрением ICC-профиля.

При выключенном сохранении EXIF удаляются EXIF и GPS. При включённом сохраняются поддерживаемые ImageIO стандартные поля EXIF/TIFF камеры и GPS: например, параметры съёмки, дата и координаты. GPS нельзя включить отдельно. Ориентация записывается как 1, а размеры в EXIF обновляются после поворота и уменьшения. Добавление метаданных не вызывает повторного сжатия JPEG с потерями.

Не переносятся закрытые поля MakerNote производителя, XMP/IPTC, старые миниатюры и поля положения объектов, ставшие недействительными после преобразования. Стандартные маркеры JPEG/ICC остаются. Это не обещание побайтового копирования всех исходных метаданных.

Обрабатывается только первый кадр: Live Photo, анимация, дополнительные HDR-данные и остальные страницы TIFF не сохраняются. Предел партии — 1 000 изображений; исходник — не более 100 миллионов пикселей, даже при запросе уменьшения; сторона выходного JPEG — не более 65 500 пикселей. Чтение форматов выполняется системным ImageIO.

## Языки и клавиатура

При первом запуске используется предпочтительный язык macOS. Выбор в правом верхнем углу можно изменить; приложение его запоминает. Доступны 16 языков:

## Сборка и тесты

Нужен Mac с Xcode и его инструментами командной строки. Приложение использует AppKit, SwiftUI, ImageIO и MozJPEG без зависимостей Swift Package Manager. Выполните из корня исходников:

```sh
git clone https://github.com/Uncas-X/LightJPEG.git
cd LightJPEG
bash build.sh
open build/LightJPEG.app
```

Включённый `Resources/bin/cjpeg` уже универсальный. CMake нужен только для его пересборки; если кодировщик отсутствует, `build.sh` вызывает его сборку автоматически. Для явной пересборки:

```sh
bash build-engine.sh
bash build.sh
```

Скрипт использует фиксированный архив MozJPEG и проверяет SHA-256. При наличии архива в `vendor/` скачивание не требуется. Кодировщик статически связан с библиотекой JPEG; SIMD отключён в этой переносимой сборке. Во время работы используются только системные динамические библиотеки.

```sh
bash test.sh
```

Нативные тесты предпросмотра требуют активного сеанса рабочего стола macOS. Для CI без рабочего стола:

```sh
LIGHTJPEG_SKIP_UI_TESTS=1 bash test.sh
```

Если система не может создать тестовый HEIC, этот случай явно пропускается. Для дополнительной проверки можно передать существующий файл, например [образец libheif](https://github.com/strukturag/libheif/blob/master/examples/example.heic):

```sh
LIGHTJPEG_HEIC_FIXTURE="/absolute/path/example.heic" bash test.sh
# Без тестов интерфейса:
LIGHTJPEG_SKIP_UI_TESTS=1 LIGHTJPEG_HEIC_FIXTURE="/absolute/path/example.heic" bash test.sh
```

Образец нужен только тестам; приложение не скачивает его. Основные каталоги: `Sources/`, `Tests/`, `Resources/bin/`, `Resources/Licenses/`; результат сборки — `build/LightJPEG.app`.

## Что проверено

Отчёт о проверке фиксирует успешные тесты ориентации, изменения размера, белого фона, sRGB, EXIF/GPS, неизменности исходников, отмены, автоматического сохранения, конфликтов имён, длинных Unicode-имён и очистки промежуточных файлов. Для JPEG, PNG, TIFF и существующего HEIC подтверждено совпадение всего кодированного тела JPEG до и после добавления метаданных. Также проверены 16 локалей, выбор языка/RTL и нативное пиксельное сравнение, включая 40 утверждений о масштабе и взаимодействиях.

Среда проверки: Intel iMac, macOS 15.7.9, Xcode 26.3 / Swift 6.2.4. На реальном оборудовании запускалась **только Intel-версия**. Arm64 перекрёстно скомпилирован и включён в пакет; проверки на Apple Silicon здесь не было. Проверены архитектуры, системные зависимости и подписи. В отчёте есть визуальные проверки китайского, немецкого и арабского интерфейса версии 1.1; для 1.0 — также английского и хинди. Это не означает ручной проверки каждого экрана всех языков на обеих архитектурах.

Приложение подписано локальной подписью ad-hoc, без Apple Developer ID и нотариализации Apple. macOS может запросить разрешение на открытие.

Один пример: [демонстрационная фотография Picdiet](https://www.picdiet.com/img/photographer.jpg), 984 065 байт, 1920 × 1280, при качестве 75 стала примерно 155 KB — на 84% меньше. Это результат одного изображения, не гарантия; фотография в приложение не включена.
