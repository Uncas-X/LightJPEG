# LightJPEG 1.1.1

[언어 목록](../../README.md) · [최신 버전 다운로드](https://github.com/Uncas-X/LightJPEG/releases/latest)

LightJPEG는 MozJPEG 4.1.5를 내장한 macOS 네이티브 오프라인 이미지 압축 앱입니다. 이미지를 업로드하지 않으며, 실행할 때 별도의 의존 프로그램을 설치할 필요가 없습니다. 앱 파일명은 `LightJPEG.app`입니다. macOS 13 이상을 지원하는 Universal 앱으로 Intel과 Apple Silicon 아키텍처가 모두 포함됩니다. Intel Mac의 macOS 15.7.9에서 실기기 검증을 마쳤습니다. arm64는 교차 컴파일만 완료했으며 실기기 검증은 아직 하지 않았습니다. 배포본은 ad hoc 서명을 사용하며 Apple 공증을 받지 않았습니다.

인터페이스와 설명 문서는 16개 언어를 지원합니다: 简体中文, English, 繁體中文, 日本語, 한국어, Français, Deutsch, Español, Italiano, Português (Brasil), Русский, العربية, हिन्दी, Türkçe, Nederlands, Polski. 인터페이스는 기본적으로 시스템 언어를 따르며 수동 선택도 기억합니다. 아랍어에서는 오른쪽에서 왼쪽으로 배치됩니다.

## 사용 방법

1. '이미지 추가'를 클릭하거나 이미지 또는 폴더를 드래그해 놓습니다. JPEG, PNG, HEIC/HEIF, TIFF, WebP, BMP를 입력으로 지원하며 결과는 JPEG로 저장합니다.
2. 품질, 크기, 색상 옵션을 선택합니다. 기본 품질은 75이며 원본 크기를 유지합니다. 긴 변의 최대 길이를 정해 축소할 수 있지만 확대하지는 않습니다. 4:4:4는 텍스트와 색상 경계에 유용하지만 파일이 커질 수 있습니다. JPEG는 손실 압축입니다. 75는 인코더 품질 값이며, 원본 화질의 75%를 유지한다는 뜻이나 일정한 압축률을 보장하는 수치가 아닙니다.
3. 'EXIF 정보 유지'는 기본적으로 꺼져 있습니다. 켜면 GPS 위치도 함께 보존하며 별도 GPS 스위치는 없습니다. '모두 압축'을 클릭하고 저장 폴더를 선택한 다음 '압축 및 저장'을 누르면 이미지가 완료될 때마다 자동으로 저장됩니다. 폴더 선택을 취소하면 이전 결과가 유지됩니다.

파일명은 원래 이름에 `_compressed`를 붙이고, 같은 이름이 있으면 고유 번호를 추가합니다. 원본이나 기존 파일을 덮어쓰지 않습니다. 압축을 중지하거나 목록을 지우거나 앱을 종료해도 이미 저장한 이미지는 남아 있습니다. 미리보기 제목줄의 내보내기 버튼은 제거되었지만 메뉴와 이미지의 오른쪽 클릭 메뉴에서는 여전히 다른 이름으로 저장할 수 있습니다. 압축은 성공했으나 자동 저장에 실패한 결과도 이 기능으로 다시 저장할 수 있습니다. 크기와 절약한 공간은 현재 선택한 이미지 하나를 기준으로 표시됩니다.

## 비교 보기와 이미지 처리

'전체 이미지 맞춤'은 이미지 전체를 창 안에 표시합니다. '1:1 픽셀'은 전체 해상도를 읽어 출력 이미지의 한 픽셀을 화면의 물리적 한 픽셀에 대응시키며 Retina 배율도 정확히 반영합니다. 스크롤하거나 이미지를 드래그하여 이동하고 구분선을 드래그하여 전후를 비교합니다. 출력 크기를 줄였으면 원본을 출력 크기에 맞춰 같은 영역끼리 비교합니다.

투명 영역은 흰색으로 채우고 색상을 sRGB로 변환하여 ICC 프로파일을 포함하며 이미지 방향을 정규화합니다. EXIF 보존을 켜면 표준 Exif, ExifAux, TIFF, GPS 필드를 보존하고 방향과 크기를 바로잡습니다. 메타데이터를 기록할 때 손실 인코딩을 다시 하지 않습니다. MakerNote, XMP/IPTC, 이전 축소판, 애니메이션, Live Photo의 연결 콘텐츠, HDR 보조 데이터는 보존하지 않습니다. 여러 페이지나 프레임이 있는 파일은 첫 프레임만 처리합니다.

한 번에 최대 1,000개 이미지, 입력은 최대 100 MP(1억 픽셀), 출력은 한 변당 최대 65,500픽셀까지 처리합니다. 결과가 원본 파일보다 크면 품질을 낮춰 보세요.

| 단축키 | 동작 |
| --- | --- |
| `⌘O` | 이미지 추가 |
| `⌘Return` | 모두 압축(저장 위치 선택) |
| `Esc` | 진행 중인 압축 취소 |
| `⌘S` | 선택한 결과를 다른 이름으로 저장 |
| `⌘⇧R` | 저장 폴더 열기 |
| `⌘Q` | 종료 |

## 빌드와 검증

Xcode와 명령줄 도구를 설치하고 저장소 루트에서 실행합니다.

```sh
bash build.sh
```

`build/LightJPEG.app`이 생성됩니다. 내장 인코더를 다시 빌드하려면 CMake도 필요합니다.

```sh
bash build-engine.sh
```

인코더 버전은 MozJPEG `v4.1.5`로 고정되어 있습니다. 저장소에 `vendor/mozjpeg-v4.1.5.tar.gz`가 포함되어 있으므로 빌드 도구가 준비되어 있으면 오프라인으로 다시 빌드할 수 있습니다. 압축 파일의 SHA-256은 다음과 같습니다.

```text
9fcbb7171f6ac383f5b391175d6fb3acde5e64c4c4727274eade84ed0998fcc1
```

전체 테스트에는 로그인된 macOS 데스크톱 세션이 필요합니다. 화면이 없는 환경에서는 네이티브 상호작용 테스트를 건너뛸 수 있습니다. `LIGHTJPEG_HEIC_FIXTURE`로 기존 HEIC 파일을 테스트 자료로 지정할 수 있습니다.

```sh
bash test.sh
LIGHTJPEG_SKIP_UI_TESTS=1 bash test.sh
LIGHTJPEG_HEIC_FIXTURE=/path/to/sample.heic bash test.sh
```

검증 범위는 8가지 이미지 방향, 크기 조정, 4개 형식의 메타데이터 보존과 이중 손실 인코딩 방지, 안전한 다른 이름 저장, 자동 저장, 취소, 저장 실패 후 복구입니다. 현지화 검증은 16 × 94개 문구 키와 33개 언어·지역 사례를 포함합니다. 픽셀 비교에는 네이티브 상호작용 검증 항목 40개가 있으며, 중국어·독일어·아랍어 화면과 이미지 2개가 있는 목록에서 선택한 이미지 하나의 통계도 확인했습니다.

## 변경 내역과 라이선스

- **1.1.1**: 미리보기 제목줄의 내보내기 버튼을 제거하고 앱 이름에서 버전 번호를 뺐습니다.
- **1.1.0**: 이미지별 자동 저장, 1:1 픽셀 비교, GPS를 포함하는 단일 EXIF 스위치, 선택 이미지별 통계를 추가했습니다.
