# LightJPEG 1.1.1

LightJPEG تطبيق أصلي لضغط الصور على macOS 13 أو أحدث. تتم المعالجة محليًا بالكامل، دون رفع الصور أو استخدام واجهات API عبر الإنترنت، ودون إعلانات أو قياس استخدام. يتضمن التطبيق MozJPEG، ولا يحتاج تشغيله إلى Homebrew أو Node.js أو Python. تحتوي الحزمة الشاملة على نسختَي Intel وApple Silicon.

## البدء

1. افتح `LightJPEG.app`. يمكنك نقله إلى مجلد التطبيقات.
2. أضف الصور، أو اسحب ملفات ومجلدات إلى النافذة. الصيغ المدعومة: JPEG وPNG وHEIC/HEIF وTIFF وWebP وBMP. تُقرأ المجلدات الفرعية وتُستبعد مسارات الملفات المكررة.
3. اختر الجودة؛ القيمة الافتراضية 75. يمكنك تحديد طول الضلع الأكبر أو الاحتفاظ بالأبعاد الأصلية. لا تُكبَّر الصور الصغيرة. يحافظ الخيار 4:4:4 على تفاصيل الحواف الملونة، مثل النصوص، بينما ينتج 4:2:0 الافتراضي عادةً ملفات أصغر.
4. فعّل حفظ معلومات EXIF عند الحاجة. هذا المفتاح الواحد يشمل GPS أيضًا، وهو متوقف افتراضيًا.
5. اضغط «ضغط الكل»، ثم اختر مجلد الإخراج وأكّد الاختيار بزر «ضغط وحفظ». تُحفظ كل صورة تلقائيًا فور اكتمال معالجتها.
6. اختر صورة من القائمة لمقارنتها، واستخدم زر فتح مجلد الإخراج للوصول إلى الملفات المحفوظة.

ضغط JPEG فاقد لبعض المعلومات. الرقم 75 إعداد للمرمّز، وليس نسبة جودة محفوظة أو وعدًا بتقليل الحجم بنسبة 75%. قد تكبر الصور الصغيرة أو المضغوطة سابقًا؛ يعرض التطبيق النتيجة الفعلية ولا يستبدلها بنسخة من الأصل.

## الحفظ والإلغاء

كل النتائج بصيغة JPEG. تُضاف اللاحقة `_compressed` إلى الاسم، ويُضاف رقم عند وجود اسم مطابق. لا تُستبدل الصور الأصلية أو الملفات الموجودة. تُنشئ إعادة الضغط ملفات جديدة.

إلغاء نافذة اختيار المجلد لا يبدأ المعالجة ولا يمس النتائج السابقة. تبقى الملفات المحفوظة على القرص بعد إلغاء المهمة أو مسح القائمة أو إغلاق التطبيق. قد يكتمل نسخ النتيجة الحالية إلى قرص بطيء قبل توقف بقية الطابور.

إذا نجح الضغط وتعذّر الحفظ، تبقى النتيجة متاحة في الجلسة الحالية. اخترها واحفظ نسخة في مجلد آخر من قائمة «ملف» أو القائمة السياقية للصورة أو بالاختصار `⌘S`. في الإصدار 1.1.1 أُزيل زر التصدير من منطقة المعاينة؛ الحفظ التلقائي يكفي للاستخدام المعتاد. استعد النتائج المؤقتة غير المحفوظة قبل مسح القائمة أو إعادة الضغط أو الخروج، إذ قد تُحذف عندها.

## المقارنة والإحصاءات

الحجم الأصلي وحجم النتيجة ونسبة التوفير وعدد البايتات الموفَّرة أسفل المعاينة تخص **الصورة المحددة**، لا مجموع الدفعة. تُعرض `—` للنتيجة قبل الضغط. تعرض رسالة اكتمال المهمة عدد الملفات على مستوى الدفعة بصورة منفصلة.

- **«الصورة كاملة» (Fit):** يعرض الصورة كاملة.
- **1:1:** يقرأ الصورة بدقتها الكاملة؛ يقابل كل بكسل في النتيجة بكسلًا فعليًا واحدًا على الشاشة، بما في ذلك شاشات Retina. استخدم العجلة أو لوحة التتبع للتمرير، أو اسحب مساحة الصورة للتحريك. يبقى سحب خط الفصل مخصصًا لتغيير حد المقارنة.

عند تصغير الصورة، يعتمد مقياس 1:1 على بكسلات النتيجة، وتُطابَق الصورة الأصلية مع المنطقة نفسها للمقارنة. قبل الضغط، تُعرض الصورة الأصلية بمقياس 1:1.

## EXIF والألوان والحدود

يُصحَّح اتجاه الصورة وفق معلومات دوران EXIF وانعكاسه. تُملأ المناطق الشفافة بالأبيض، وتُحوَّل الألوان إلى sRGB مع تضمين ملف ICC.

عند إيقاف حفظ EXIF تُزال بيانات EXIF وGPS. وعند تشغيله تُحفظ حقول الكاميرا القياسية EXIF/TIFF التي يدعمها ImageIO، مع GPS، مثل إعدادات الالتقاط والتاريخ والإحداثيات. لا يوجد مفتاح GPS مستقل. يُضبط الاتجاه على 1، وتُحدَّث أبعاد EXIF وفق النتيجة بعد الدوران والتصغير. لا تؤدي إضافة البيانات الوصفية إلى إعادة ضغط JPEG ضغطًا فاقدًا.

لا تُنسخ حقول MakerNote الخاصة بالشركات، أو XMP/IPTC، أو المصغرات القديمة، أو حقول مواضع العناصر التي لم تعد صالحة بعد التحويل. تبقى علامات JPEG/ICC القياسية. لا يعني ذلك حفظ كل البيانات الوصفية الأصلية بايتًا ببايت.

تُعالَج الصورة أو اللقطة الأولى فقط؛ لا تُحفظ Live Photo أو الحركة أو بيانات HDR المساعدة أو بقية صفحات TIFF. الحد الأقصى للدفعة 1,000 صورة، وللصورة الأصلية 100 مليون بكسل حتى عند طلب التصغير، ولأي ضلع في JPEG الناتج 65,500 بكسل. تعتمد قراءة الصيغ على ImageIO في النظام.

## البناء والاختبارات

يلزم جهاز Mac مثبت عليه Xcode وأدواته لسطر الأوامر. يستخدم التطبيق AppKit وSwiftUI وImageIO وMozJPEG، دون اعتماديات Swift Package Manager. نفّذ الأوامر التالية من مصدر المشروع:

```sh
git clone https://github.com/Uncas-X/LightJPEG.git
cd LightJPEG
bash build.sh
open build/LightJPEG.app
```

الملف المرفق `Resources/bin/cjpeg` شامل للمعماريتين. يلزم CMake فقط لإعادة بناء المرمّز؛ وإذا كان ملف المرمّز مفقودًا، يستدعي `build.sh` بناءه تلقائيًا. لإعادة بنائه صراحةً:

```sh
bash build-engine.sh
bash build.sh
```

يستخدم السكربت أرشيف MozJPEG بإصدار ثابت ويتحقق من SHA-256. لا يحتاج تنزيلًا إذا كان الأرشيف موجودًا في `vendor/`. ترتبط مكتبة JPEG بالمرمّز ربطًا ثابتًا، وتعطَّل SIMD في هذه البنية المحمولة. اعتماديات التشغيل الديناميكية هي مكتبات النظام فقط.

```sh
bash test.sh
```

تحتاج اختبارات المعاينة الأصلية إلى جلسة سطح مكتب macOS مسجَّل الدخول إليها. في بيئة CI بلا سطح مكتب:

```sh
LIGHTJPEG_SKIP_UI_TESTS=1 bash test.sh
```

إذا تعذّر على النظام إنشاء عينة HEIC للاختبار، تُعرض رسالة تخطٍّ صريحة. يمكن توفير ملف موجود، مثل [عينة libheif](https://github.com/strukturag/libheif/blob/master/examples/example.heic)، للتحقق الإضافي:

```sh
LIGHTJPEG_HEIC_FIXTURE="/absolute/path/example.heic" bash test.sh
# دون اختبارات واجهة المستخدم:
LIGHTJPEG_SKIP_UI_TESTS=1 LIGHTJPEG_HEIC_FIXTURE="/absolute/path/example.heic" bash test.sh
```

العينة للاختبارات فقط، ولا ينزّلها التطبيق. توجد الشيفرة في `Sources/` والاختبارات في `Tests/` والمرمّز في `Resources/bin/` والتراخيص في `Resources/Licenses/`. ناتج البناء هو `build/LightJPEG.app`.

## نتائج التحقق

يسجل تقرير التحقق نجاح اختبارات الاتجاه والتصغير والخلفية البيضاء وsRGB وEXIF/GPS وعدم تغيير الأصول والإلغاء والحفظ التلقائي وتعارض الأسماء وأسماء Unicode الطويلة وتنظيف الملفات المرحلية. ثبُت تطابق جسم JPEG المشفّر بايتًا ببايت قبل إضافة البيانات الوصفية وبعدها، لمصادر JPEG وPNG وTIFF وعينة HEIC موجودة. شملت الاختبارات 16 لغة وتفضيلات اللغة وRTL، إضافة إلى المقارنة الأصلية على مستوى البكسل و40 تحققًا للمقياس والتفاعل.

بيئة التحقق: Intel iMac، وmacOS 15.7.9، وXcode 26.3 / Swift 6.2.4. جرى التشغيل الفعلي على **Intel فقط**. أُجري بناء متقاطع لـarm64 وأُدرج في الحزمة، دون اختبار على جهاز Apple Silicon في هذه البيئة. فُحصت المعماريات واعتماديات النظام والتوقيعات. يشمل التقرير مراجعات مرئية للصينية والألمانية والعربية في الإصدار 1.1، وللإنجليزية والهندية أيضًا في 1.0؛ لا يعني ذلك فحص كل شاشة بكل لغة على المعماريتين.

التوقيع محلي من نوع ad-hoc، وليس Apple Developer ID، ولم يخضع التطبيق لتوثيق Apple عبر خدمة notarization. قد يطلب macOS الإذن بفتحه.

## سجل التغييرات

- **1.1.1:** إزالة زر التصدير من المعاينة، مع بقاء حفظ نسخة اختياريًا عبر القائمة والقائمة السياقية و`⌘S`. اسم التطبيق `LightJPEG.app` دون رقم إصدار.
